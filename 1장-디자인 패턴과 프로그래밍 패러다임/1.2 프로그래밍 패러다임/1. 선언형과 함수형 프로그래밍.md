## 프로그래밍 패러다임?
> ✨프로그래머에게 **프로그래밍의 관점**을 갖게 해주는 개발 방법론

### 선언형 프로그래밍

```
선언형 프로그래밍: 어떻게(How)할 건지 나타내기보다 무엇(What)을 할 건지 설명하는 방식
```
- 함수형 프로그래밍

### 명령형 프로그래밍 

```
명령형 프로그래밍: 무엇(What)을 할 건지 나타내기보다 어떻게(How)할 건지 설명하는 방식
```
- 객체지향형 프로그래밍
- 절차지향형 프로그래밍


<br>

## **1\. 선언형과 함수형 프로그래밍**

함수형 프로그래밍은 선언형 패러다임의 일종. 

**순수 함수**를 쌓아 로직을 구현하고 **고차 함수**를 통해 재사용성을 높인 프로그래밍 패러다임이다.

---

### 💡 순수 함수?

출력을 입력에만 의존하는 것

> **🤔** 이게 무슨 소리지? 

#### ✅ 순수 함수의 조건

1.  **같은 입력 → 항상 같은 출력**
2.  **부작용(side effect)이 없음**

#### 부작용 예시:

-   전역 변수 수정 ❌
-   콘솔 출력 ❌
-   외부 상태 의존 ❌

```
int factorial(int n) {
    if (n == 0) return 1;
    return n * factorial(n - 1);
}
```

같은 팩토리얼이어도 아래의 경우는 **순수 함수가 아님❌❌**

```
int factorial(int n) {
    System.out.println(n);   // 부작용(side effect)
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

#### 콘솔 출력은 :

-   **함수** **밖의 세계(IO)** 를 변경함
-   반환값과 무관하게 **외부 상태에 흔적**을 남김
-   테스트·캐싱·병렬 실행에 영향 줌

---

### 💡고차 함수?

함수가 함수를 값처럼 매개변수로 받아 로직을 생성할 수 있는 것

> 🤔 ...무슨 소리지?

고차 함수의 조건은 다음과 같다.

-   **함수를 인자로 받는다**
-   **함수를 반환한다**

---

#### ▶️ 함수를 인자로 받는 경우 :

```
static int apply(int x, Function<Integer, Integer> f) {
    return f.apply(x);
}
```

#### ▶️ 함수를 반환하는 경우 :

```
static Function<Integer, Integer> multiplier(int k) {
    return x -> x * k;
}
```

---

### ✨ 고차 함수의 예시: 자바 스트림(stream) 함수

```
List<Integer> nums = List.of(1, 2, 3);

List<Integer> squared =
    nums.stream()
        .map(n -> n * n)  
        .toList();
```

**(주의!)** **모든 스트림 함수가 고차 함수는 아니다❌❌**

```
stream.count();
stream.findFirst();
stream.toList();
```

### 💡 커링 함수

여러 개의 인자를 받는 함수를 단 하나의 인자만 받는 함수로 만드는 과정

```
Function<Integer, Function<Integer, Integer>> add = a -> b -> a + b;
```

```
Function<Integer, Integer> add3 = add.apply(3);
int result = add3.apply(5);
```

**사용 이유 1:** 설정을 고정하기 위해

```
addTen(price, 10);   // 반복하기 번거로움
addTen(price, 10);
addTen(price, 10);
```

```
Function<Integer, Integer> add10 = add.apply(10);
add10.apply(price);
add10.apply(price);
```

> 🤔 애초에 add 함수를 a + 10 으로 설정하면 되는 거 아닌가? 

**▶️ 재사용성이 떨어짐 !!**

**사용 이유 2:** 인자 하나를 받는 함수에 사용하기 위해

```
stream.map(x -> x + 10);
```

```
Function<Integer, Integer> add10 = add.apply(10);
stream.map(add10);
```

### 💡일급 객체?

함수를 일반적인 값(숫자나 문자열 등)과 동일하게 취급하여 제약 없이 다룰 수 있는 대상

※ 자바의 람다식, 익명 클래스는 변수나 매개변수에 할당할 수 있고, 리턴값으로도 사용할 수있기 때문에 일급 객체의 요건을 충족한다.

#### 일급 객체 특징

-   변수나 메소드에 함수를 할당할 수 있음
-   함수 안에 함수를 매개변수로 담을 수 있음
-   함수가 함수를 반환할 수 있음
