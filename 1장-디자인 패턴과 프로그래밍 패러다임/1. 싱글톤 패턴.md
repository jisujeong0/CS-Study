## **1\. 싱글톤 패턴**

**하나의 클래스에는 오직 하나의 인스턴스만**

ex. 데이터베이스 연결 설정, 자원 풀 관리 (설정은 여러 개가 있으면 안되기 때문에)


### 💡 전역 변수와의 차이점?

싱글톤 패턴은 전역 변수처럼 객체 인스턴스를 **어디서든지 접근 가능**, 전역 변수보다 단점이 적다.

-   전역 변수의 단점 : 객체가 자원을 많이 차지한다고 가정할 때, 변수가 한 번도 쓰이지 않는다면 자원 낭비이다. 싱글톤은 **필요할 때만 만들 수 있다.**

### 고전적인 싱글톤 패턴

```
public class Singleton {
    private static Singleton uniqueInstance;
    
    // 기타 인스턴스 변수
    private Singleton() {}
    
    public static Singleton getInstance() {
    	if (uniqueInstance == null) {
        	uniqueInstance = new Singleton();
        }
    }
}
```

싱글톤 패턴이 하나의 인스턴스만 가질 수 있는 이유: private 생성자만 가지고 있기 때문에, 두 번 이상 만들 수 없다.

**!! 멀티스레드 환경에서는 getInstance()에서 충돌이 일어나 두 개 이상 생성될 수 있음**

### 💡대안이 있다면?

#### 1️⃣ 동기화

```
public static synchronized Singleton getInstance() {}
```

한 스레드가 메소드 사용을 마칠 때 까지 다른 스레드는 기다려야 한다. 따라서 불필요한 오버헤드 발생 가능성이 있다.

#### 2️⃣ Lazy Initialization (CS 책 코드 참고)

```
public class Singleton {
    private static class singleInstanceHolder {
        private static final Singleton INSTANCE = new Singleton();
    }
    
    public static Singleton getInstance() {
        return singleInstanceHolder.INSTANCE;
    }
}
```

singleInstanceHolder라는 내부 클래스를 하나 더 만듦으로써, getInstance()가 호출될 때 singleInstanceHolder 클래스가 로딩되어 인스턴스를 생성하게 된다.

| Lazy Loading | ✅ |
| --- | --- |
| Thread-safe | ✅ |
| synchronized | ❌ |
| 성능 | 👍 |
| 구현 난이도 | 중 |

#### 2️⃣-1️⃣ Eager Initialization

클래스 로딩 시점에 무조건 인스턴스 생성 -> 사용하지 않을 때도 메모리 차지

#### 3️⃣ DCL(Double-Checking Locking)

인스턴스가 생성되어 있는지 확인하고, 생성되지 않은 경우에만 동기화한다.

```
public class Singleton {
    private volatile static Singleton uniqueInstance;
    private Singleton() {}
    
    public static Singleton getInstance() {
        if (uniqueInstance == null) {
        	synchronized (Singleton.class) {
                if (uniqueInstance == null) {
                    uniqueInstance = new Singleton();
                }
            }
        }
    }
}
```

> **volatile:** 멀티스레드 환경에서 최신 값과 올바른 실행 순서를 보장

2번(CS 교재 예시)을 가장 많이 쓴다고 한다.
