## **2\. 팩토리 패턴**

객체 생성을 캡슐화한다.

장점: 객체 생성 코드를 한 객체나 메소드에 넣음으로써 코드 중복 제거, 관리 용이. 

### 1️⃣ 팩토리 패턴

> 객체를 생성하기 위한 인터페이스 정의. 어떤 클래스의 인스턴스를 만들지는 서브클래스에서 결정한다.  
> 즉, 클래스의 인스턴스를 만드는 일을 서브클래스에 맡기게 된다.

### 2️⃣ 추상 팩토리 패턴

> 인터페이스를 이용하여 서로 연관되거나 의존하는 객체를 구상 클래스를 지정하지 않고도 생성한다.

|   | 객체 생성 | 사용 |
| --- | --- | --- |
| 팩토리 | 클래스(상속)     | 어떤 구상 클래스가 필요할 지 모르는 경우 |
| 추상 팩토리  | 객체(compositon) | 서로 연관된 일련의 제품을 만들어야 할 때 |

<br>

> **CODE: 피자 프랜차이즈와 원재료 팩토리**

뉴욕과 시카고에 각각 피자 프랜차이즈가 있다.

두 개의 가게는 피자를 만들기 위해 원재료를 각각 다른 팩토리에서 수급한다.

뉴욕 피자 가게에서 치즈 피자를 주문해보자.

```
1️⃣ PizzaStore nyPizzaStore = new NYPizzaStore();
2️⃣ nyPizzaStore.orderPizza("cheese");
```

> **피자**

```
public abstract class Pizza {
    String name;
    Dough dough;
    Sauce sauce;
    Cheese cheese;
    
    abstract void prepare();
    
    void bake() { // 코드 생략 }
    void cut() { // 코드 생략 }
    
    // ...
}
```

prepare는 Pizza를 상속받은 하위 클래스에서 따로 구현한다. 피자의 종류에 따라 prepare(준비할 피자의 재료)의 내부가 달라지기 때문이다.

```
public class CheesePizza extends Pizza {
    PizzaIngredientFactory ingredientFactory;
    
    public CheesePizza(PizzaIngredientFectory ingredientFactory) {
        this.ingredientFactory = ingredientFactory;
    }
    
    void prepare() {
        dough = ingredientFactory.createDough();
        sauce = ingredientFactory.createSauce();
        cheese = ingredientFactory.createCheese();
    }
}
```

예시로, 치즈 피자의 prepare() 안에는 dough와 sauce, cheese가 있다.

> **피자 가게**

```
public abstract class PizzaStore {
    public Pizza orderPizza(String type)  {   // enum 타입도 가능
    	Pizza pizza;
        
        pizza = createPizza(type);
        
        pizza.prepare();
        pizza.bake();
        pizza.cut();
        
        return pizza;
    }
    
}
```

```
public class NYPizzaStore extends PizzaStore {
    protected Pizza createPizza(String item) {
        Pizza pizza = null;
        PizzaIngredientFactory ingredientFactory = new NYPizzaIngredientFactory();
        
        if (item.equals("cheese")) {
            pizza = new CheesePizza(ingredientFactory);
        }
        else if (item.equals("veggie")) {
            pizza = new VeggiePizza(ingredientFactory);
        }
        else if (item.equals("clam")) {
            pizza = new ClamPizza(ingredientFactory);
        }
        
        return pizza;
    }
}
```

> **원재료 팩토리**

피자를 생성하기 위한 원재료가 모여있는 팩토리다. 지점에 따라 원재료의 종류가 다르다. 

```
public interface PizzaIngredientFactory {
    public Dough createDough();
    public Sauce createSauce();
    public Cheese createCheese();
}
```

```
// 뉴욕 피자 원재료
public Class NYPizzaIngredientFactory implements PizzaIngredientFactory {
    public Dough createDough() {
        return new ThinCrustDough();
    }
    public Sauce createSauce() {
        return new MarinaraSauce();
    }
    public Cheese createCheese() {
        return new ReggianoCheese();
    }
}
```

뉴욕과 시카고는 같은 피자더라도 원재료의 종류가 다르다.
