## **4\. 옵저버 패턴** 

> 한 객체의 상태가 바뀌면 그 객체에 의존하는 다른 객체들한테 연락이 가고, 자동으로 그 내용이 갱신되는 방식으로 일대다(one-to-many) 의존성을 정의한다.

#### **subject(주체):** 상태를 저장하고 있는 객체

-   옵저버로 등록하거나 옵저버 목록에서 탈퇴하고 싶을 때 subject에 존재하는 메소드 사용
-   상태가 바뀔 때마다 옵저버에게 연락하기 위한 notifyObservers() 메소드 구현 필요

#### **observer(옵저버):** subject에 의존하는 객체

-   주제의 상태가 변경되었을 때 update() 호출.

---

### ⛓️‍💥 subject와 observer의 느슨한 결합

-   subject는 observer가 observer 인터페이스를 구현한다는 것만 앎
-   옵저버는 언제든 추가 가능
-   새로운 형식의 옵저버를 추가하더라도 subject 변경할 필요 없음
-   독립적으로 재사용 가능
-   둘 중에 하나가 바뀌더라도 영향 미치지 않음

<br>

> **CODE: 날씨 데이터 업데이트**

```
public interface Subject {
    public void registerObserver(Observer o);
    public void removeObserver(Observer o);
    public void notifyObservers();
}

public interface Observer {
    public void update(float temp, float humidity, float pressure);
}
```

> **Subject**

```
public class WeatherData implements Subject {
    private ArrayList observes;
    private float temperature;
    private float humidity;
    private float pressure;
    
    public WeatherData() {
    	observers = new ArrayList();
    }
    
    // subject 인터페이스 구현
    public void registerObserver(Observer o) {
        observers.add(o);
    }
    
    public void removeObserver(Observer o) {
        int i = observers.indexOf(o);
        if (i >= 0) {
            observers.remove(i);
        }
    } 
    
    public void notifyObservers() {
        for (int i = 0; i < observers.size(); i++) {
            Observer observer = (Observer)observers.get(i);
            observer.update(temparature, humidity, pressure);
        }
    }
    
    // 기타 메소드
}
```

> **Observer**

```
public class CurrentConditionsDisplay implements Observer {
    private float temperature;
    private float humidity;
    private float weatherData;
    
    public void CurrentConditionsDisplay(Subject weatherData) {
        this.weatherData = weatherData;
        weatherData.registerObserver(this);
    }
    
    public void update(float temperature, float humidity, float pressure) {
        this.temperature = temperature;
        this.humidity = humidity;
    }
}
```

### 자바에 내장된 옵저버 패턴

```
java.util.Observable
```

-   **push 방식:** subject가 데이터를 보냄
    -   Subject가 Observer가 뭘 필요로 하는지 알아야 함
    -   변경이 많아지면 메서드 시그니처가 계속 바뀜 → 결합도 증가
-   **pull 방식:** observer가 필요할 때만 데이터를 가져감
    -   Observer가 Subject에 접근해야 함
    -   불필요한 조회가 발생할 수 있음
