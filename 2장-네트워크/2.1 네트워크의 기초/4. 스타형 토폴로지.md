## 2️⃣ 스타형 토폴로지

> 모든 장치가 하나의 중앙 장치(허브 또는 스위치)에 개별적으로 연결된 네트워크 구조.  
> LAN에서는 스타형(Star Topology)이 기본이고, 규모가 커지면 트리형(계층형) / 하이브리드형으로 확장한다.

- 중앙 장치가 통신을 중계하는 역할을 갖고 있기 때문에, 네트워크에 연결되어 있는 컴퓨터가 고장이 나도 장애가 다른 노드까지 미치지 않음! 
- **반대로** 중앙 장치가 고장난 경우, 통신 경로가 끊어지므로 네트워크 전체가 통신 불량을 일으키게 된다.

### ✨ 허브 VS 스위치 스타형 토폴로지의 차이

```
PC ─ Hub/Switch ─ PC
```

#### 1️⃣ 허브(Hub) 기반 스타형

한 PC가 보낸 패킷을 **모든 포트로 그대로 복사해서 전송 ▶️** 내부적으로는 **버스형과 동일**

```
A → Hub → B, C, D (전체)
```

**단점 (버스형 토폴로지와 동일하다)**

-   콜리전 많음
-   스니핑·스푸핑에 취약

#### 2️⃣ 스위치(Switch) 기반 스타형

스위치가 MAC 주소 테이블을 보고 **목적지 포트로만 전달**

```
A → Switch → B (만)
```

허브와는 다르게 목적지 포트로만 전달하기에 **충돌 거의 없음 / 동시에 여러 통신 가능 / 도청 어려움**

#### **장점**

-   성능 좋음
-   보안 상대적으로 강함
-   확장성 좋음

📌 **현대 LAN 표준**

| 구분 | 허브 | 스위치 |
| --- | --- | --- |
| OSI 계층 | 물리 계층 (L1) | 데이터 링크 계층 (L2) |
| 패킷 전달 | 전체 브로드캐스트 | 목적지 포트만 |
| 충돌 | 발생 O | 거의 X |
| 대역폭 | 공유 | 포트별 분리 |
| 보안 | 취약 | 상대적으로 안전 |
| 사용 여부 | ❌ 거의 없음 | ✅ 표준 |
