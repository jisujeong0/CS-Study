## 4️⃣ 링형 토폴로지

> 모든 노드가 원형으로 연결되어, 데이터가 한 방향(또는 양방향)으로 순차적으로 전달되는 구조  
> 하나의 버스에 장치를 연결하는 것은 버스형과 동일하지만, 버스형과 다르게 터미네이터 필요없음

> **토큰(Token) 방식으로 통신 ▶️**  
> 네트워크에서 전송 권한을 의미하는 토큰이 순환하고, 토큰을 가진 노드만 데이터를 보낼 수 있는 방식

1. 토큰이 네트워크를 순환  
2. 어떤 노드가 **전송할 데이터가 없으면** → 토큰을 다음 노드로 전달  
3. **데이터가 있으면** → 토큰을 잡고 데이터 전송  
4. 전송이 끝나면 → 토큰을 다시 네트워크에 방출

토큰 없이는 전송이 불가하고, 동시에 여러 노드가 전송되지 않으므로 👉 **Collision 자체가 발생하지 않음**

#### **장점**

-   충돌 거의 없음
-   데이터 흐름 예측 가능

#### **단점**

-   장치 하나만 고장 나도 전체 영향
-   확장/유지보수 어려움: 노드 추가/제거 시 네트워크 전체에 영향

📌 **거의 사용 안 함**
