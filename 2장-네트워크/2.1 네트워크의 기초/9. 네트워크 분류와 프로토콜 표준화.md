##  네트워크 분류 

### 1️⃣ LAN (Local Area Network)

👉 좁은 지역 내에서 사용하는 네트워크

> 범위: 집 / 학교 / 회사 / 한 건물 / 캠퍼스 일부

### 2️⃣ MAN (Metropolitan Area Network)

👉 도시 규모의 네트워크

> 범위: 도시 전체 / 여러 캠퍼스 또는 지점 연결

### 3️⃣ WAN (Wide Area Network)

👉 국가·대륙 단위의 광범위한 네트워크

> 범위: 국가 / 전 세계

| **구분** | **LAN** | **MAN** | **WAN** |
| --- | --- | --- | --- |
| 범위 | 건물·캠퍼스 | 도시 | 국가·대륙 |
| 속도 | 빠름 | 중간 | 상대적으로 느림 |
| 지연 | 짧음 | 중간 | 김 |
| 비용 | 낮음 | 중간 | 높음 |
| 예시 | 집/회사 | 도시망 | 인터넷 |

##  네트워크 성능 분석 명령어 

**ping:** 네트워크 상태를 확인하려는 대상 노드를 향해 일정 크기의 패킷을 전송하는 명령어. 이를 통해 해당 노드의 패킷 수신 상태와 도달하기까지의 시간, 해당 노드까지 네트워크가 잘 연결되어 있는지 확인할 수 있음.

`ping [IP 주소 또는 도메인 주소]`

**netstat:** 접속되어 있는 서비스들의 네트워크 상태를 표시하는 데 사용됨. 네트워크 접속 / 라우팅 테이블 / 네트워크 프로토콜 리스트를 보여줌. 주로 서비스의 포트가 열려 있는지 확인할 때 사용.

**nslookup:** DNS에 관련된 내용을 확인하기 위해 쓰는 명령어. 특정 도메인에 매핑된 IP를 확인하기 위해 사용.

**tracert(윈도우):** 리눅스에서는 **traceroute**, 목적지 노드까지 네트워크 경로를 확인할 때 사용하는 명령어. 목적지 노드까지의 구간 중 어느 구간에서 응답 시간이 느려지는지 등을 확인.

##  네트워크 프로토콜 표준화 

### **네트워크 프로토콜?**

> 다른 장치들끼리 데이터를 주고받기 위해 설정된, 공통된 인터페이스  
> 서로 다른 회사·국가·장비라도 같은 규칙(프로토콜)을 쓰도록 정해둔다.

| **기관** | **역할** |
| --- | --- |
| **IETF** | 인터넷 프로토콜 (TCP/IP, HTTP) |
| **IEEE** | 하드웨어/네트워크 기술 (Ethernet, Wi-Fi) |
| **ISO** | 국제 표준 (OSI 7계층) |
| **ITU-T** | 통신 규격 |

#### **표준화 예시**

-   HTTP: 어느 브라우저든 웹 접속 가능
-   TCP/IP: 전 세계 인터넷 공통 언어
-   Ethernet: 회사 바뀌어도 LAN 사용 가능
-   Wi-Fi: 어떤 기기든 AP 접속 가능
