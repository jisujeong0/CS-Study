## 6️⃣ 하이브리드형 (Hybrid Topology)

> 두 개 이상의 토폴로지를 결합해서 구성한 네트워크 구조

### 구조 예시

#### **스타 + 트리 (가장 흔함)**

```
        Core Switch
             |
     ───── Distribution ─────
      |            |         |
    (Star)       (Star)    (Star)
```

-   각 부서/층: 스타형
-   전체 연결: 트리형

**👉 기업 LAN의 표준 구조**

#### **스타 + 메시 (이중화)**

```
Access ─ Core ─ Access
    ╲         ╱
       Backup
```

-   핵심 구간만 메시로 이중화
-   장애 대비

**장점**

-   환경에 맞게 구조 선택 가능
-   유연

**단점**

-   설계 난이도 높음
-   관리 복잡

📌 **실제 네트워크 대부분**
