## 1️⃣ 애플리케이션 계층

> 애플리케이션 계층은 사용자 애플리케이션이 네트워크 서비스를 이용하기 위한 프로토콜을 제공하는 계층  
> 👉 **무엇을 주고받을지**를 담당

-   브라우저
-   메일 클라이언트
-   FTP 클라이언트

이런 것들이 **직접 사용하는 프로토콜**에 해당됨.

> 📌 OSI로 치면 Application + Presentation + Session을 전부 합친 계층

### ✨ 애플리케이션 계층의 역할

-   데이터 형식 / 통신 규약 정의
-   세션 관리
-   암호화/인코딩 (일부)

#### 대표 프로토콜

| **프로토콜** | **역할** |
| --- | --- |
| HTTP | 웹 페이지 전송 |
| HTTPS | 암호화된 웹 통신 |
| FTP | 파일 전송 |
| SMTP | 메일 보내기 |
| POP3 | 메일 받기 |
| IMAP | 메일 동기화 |
| DNS | 도메인 → IP 변환 |
| DHCP | IP 자동 할당 |
| Telnet | 원격 접속 |
