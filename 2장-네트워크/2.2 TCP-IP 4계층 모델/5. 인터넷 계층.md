## 3️⃣ 인터넷 계층

> 네트워크 간 데이터를 IP 주소로 지정된 목적지까지 전달하기 위해 사용되는 계층  
> TCP/IP에서 IP가 있는 계층

> 📌 OSI로는 **네트워크 계층 (3계층)**

| **프로토콜** | **역할** |
| --- | --- |
| IP | 패킷 전달 |
| ICMP | 오류·상태 메시지 |
| ARP | IP → MAC 변환 |
| IPsec | IP 보안 |

### 🌎 인터넷 계층의 역할

-   장치마다 고유한 IP 주소를 사용하여 데이터의 출발지와 목적지를 식별
-   **라우팅 (Routing):** 인터넷 네트워크를 통해 목적지까지 가장 효율적인 경로를 결정해 전달
-   상위 계층에서 받은 데이터를 **패킷으로 캡슐화**
-   **비연결형**
