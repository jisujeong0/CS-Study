**인터넷 프로토콜 스위트(Internet Protocol Suite)**

> 인터넷에서 컴퓨터들이 서로 정보를 주고받는 데 쓰이는 프로토콜의 집합

ex. TCP/IP 4계층 모델, OSI 7계층 모델

##  OSI와 TCP/IP 

-   **OSI**: 개념·이론 중심의 7계층 참조 모델
-   **TCP/IP**: 실제로 인터넷에서 쓰이는 4계층 실무 모델

### OSI 모델 (7계층)

👉 **네트워크를 이해하고 설명하기 위한 이론적 모델**

| 계층  | 역할 |
| --- | --- |
| 7 응용 (Application) | 사용자와 가장 가까움 (HTTP, FTP 등) |
| 6 표현 (Presentation) | 인코딩, 압축, 암호화 |
| 5 세션 (Session) | 세션 연결/유지/종료 |
| 4 전송 (Transport) | 신뢰성, 흐름 제어 (TCP, UDP) |
| 3 네트워크 (Network) | 라우팅, IP |
| 2 데이터링크 (Data Link) | MAC 주소, 프레임 |
| 1 물리 (Physical) | 케이블, 전기 신호 |

- - - 

### TCP/IP 모델 (4계층)

👉 **실제 인터넷에서 사용하는 현실 모델**

| TCP/IP 계층 | OSI 대응 |
| --- | --- |
| 응용 (Application) | OSI 7,6,5 |
| 전송 (Transport) | OSI 4 |
| 인터넷 (Internet) | OSI 3 |
| 링크, 네트워크 인터페이스 | OSI 2,1 |
