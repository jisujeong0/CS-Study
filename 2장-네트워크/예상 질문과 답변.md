## 2주차: 네트워크
### 1. OSI 7계층과 TCP/IP 4계층의 차이점은 무엇인가요?
OSI 7계층은 이론적으로 구분한 계층으로, 애플리케이션 계층, 프레젠테이션 계층, 세션 계층, 전송 계층, 네트워크 계층, 데이터 링크 계층, 물리 계층으로 이루어져있습니다. TCP/IP 4계층은 실제 사용하는 모델로, 애플리케이션 계층, 전송 계층, 인터넷 계층, 링크 계층으로 이루어져 있습니다.

### 2. HTTP/2를 설명하고 장점 두 가지를 설명하세요.
HTTP/2는 HTTP/1.x 버전의 단점을 개선한 프로토콜입니다.

허프만 코딩 기반의 HPACK 헤더 압축을 통해 중복 헤더 전송을 줄이고, 하나의 TCP 연결에서 여러 요청을 동시에 처리하는 멀티플렉싱 방식을 이용해 HOL 문제를 완화했습니다.

#### 추가질문: HOL 문제가 무엇인가요?
HTTP/1.x에서 발생한 현상으로, 파이프라이닝 사용 시, 앞선 요청의 응답이 지연되면 뒤의 요청까지 함께 지연되는 문제입니다.

### 3. HTTP와 HTTPS의 차이점을 설명해주세요.
HTTP와 HTTPS의 가장 큰 차이점은 SSL/TLS 프로토콜입니다.

HTTP는평문 통신 방식을 사용하기 때문에 메시지가 도청되거나 변조될 수 있습니다. 이러한 문제를 해결하기 위해 HTTPS는 보안을 제공하는 SSL/TLS 프로토콜을 사용합니다. SSL/TLS는 인증을 통해 서버의 신원을 확인하고, 암호화 알고리즘을 통해 도청하더라도 내용을 알 수 없게 방지하고, 해싱 알고리즘을 통해 데이터가 변조되었는지 확인함으로써 데이터 무결성을 검증합니다.

### 4. 브라우저에서 www.naver.com을 입력하고, 화면이 띄워지기 까지의 과정을 설명해주세요.
사용자가 브라우저에 URL을 입력하면, DNS주소를 통해 도메인에 대응하는 IP주소를 조회합니다. 조회된 IP 주소를 가지고 TCP 기반 3-way handshake 방식을 이용해 서버와 연결을 수립합니다. 이 때 HTTPS라면 TLS 핸드셰이크로 보안 연결을 설정합니다. 서버와 연결되면 브라우저는 HTTP 요청을 보내고, 서버는 리소스를 HTTP 응답에 담아 전송합니다. 브라우저는 응답을 받아 화면에 출력합니다.

HTTP/3인 경우 UDP 기반 QUIC 프로토콜을 이용해 서버를 연결합니다.
